1. Create a new profile in the Floccus panel
2. Select Karakeep as your sync method
3. Optionally set a name for your new profile.
4. The following screen shows the connection settings.
5. First you will need to enter the URL of your Karakeep server, e.g. https://karakeep.example.com
6. Then enter an API key. Entering your account password will not work, instead you have to generate an API key in the Karakeep settings for floccus.
7. Enter the name of a list to sync to (by default “Floccus”). All your bookmarks as well as any folders you have will be created under this list. Only links under this list will be synced with your browser.
8. Finally, you can choose which bookmarks folder to sync to that list. Click on the folder icon to select a folder in your bookmarks. You will need to pick a folder before you can continue, and it’s a good idea to choose a dedicated folder to avoid syncing something that you don’t want synced.
9. Make sure to disable your native browser bookmark sync service, because it is likely incompatible with floccus. (This can cause frequent duplication of bookmarks.)

Note that Karakeep can only sync `http(s):` links, does not keep the order of your bookmarks across syncs and cannot be used with end-to-end encryption.
